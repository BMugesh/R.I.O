## 1. Architectural Overview

Milestone 5.x implements a **Persistent Local Voice Runtime and Natural Conversational Agent** layer on top of R.I.O.'s M1–M5 architecture.

The system runs entirely locally on Windows, detaches into the background upon invocation, manages an active PID lock, wakes on phonetic keyword detection, speaks naturally through a female voice synthesizer, and executes laptop actions through the M5 Intelligent Planner and Parallel DAG Executor.

## 2. Core Operational Guarantees

1. **Local CLI + Local Background Runtime**:
   - `rio run` starts the local daemon detached (`CREATE_NO_WINDOW | DETACHED_PROCESS` on Windows), verifies the PID file, outputs the official banner, and exits the foreground process immediately.
   - Zero WebSocket, phone, or external web service requirements.

2. **Standby State**:
   - 100% local acoustic VAD and keyword detection.
   - Zero audio frames streamed to Groq while in `STANDBY`.

3. **Wake Phrase & Immediate Response**:
   - Wakes on `"Hey RIO"` (or aliases like `"Wake up RIO"`, `"Friday"`).
   - Immediately responds with `"Yes?"` via Female TTS and enters `ACTIVE`.

4. **Continuous Active Dialogue**:
   - After executing an action or responding to a query, R.I.O. **remains in the `ACTIVE` state**.
   - Subsequent user utterances are processed directly without requiring the wake phrase.

5. **Interruption & Control Commands**:
   - `"RIO, stop"`: Instantly interrupts active TTS speech and cancels active cancellable tasks.
   - `"RIO, standby"`: Returns to `STANDBY` ("Standing by.").
   - `"RIO, shut down"` / `rio stop`: Initiates clean daemon shutdown ("Shutting down.") with full resource recovery.

6. **Female Voice Synthesis**:
   - Default female assistant voice (`Microsoft Zira Desktop` / `Microsoft Heera Desktop` / `en-IN`).
   - Automated text filtering removes markdown formatting, execution traces, and raw JSON.

## 3. CLI Command Reference

| Command | Action |
|:---|:---|
| `rio run` | Starts background voice daemon and outputs ASCII banner |
| `rio run -f` / `--foreground` | Runs daemon in current console session for debugging |
| `rio status` | Displays daemon PID, uptime, state, and voice subsystem metrics |
| `rio stop` | Gracefully shuts down background daemon and cleans up PID |
| `rio restart` | Stops and restarts the background daemon |
| `rio test full` | Runs the governed 227-test suite with leak detection |

# R.I.O. v0.2.0 Release Notes
**Milestone 2 — Always-On Background Runtime**
*Release Date: September 2026*

---

## Executive Summary

R.I.O. (Reasoning • Intelligence • Orchestration) v0.2.0 delivers an always-on, resilient background runtime enabling persistent daemon execution, device registration, bidirectional WebSocket communication, granular capability permissions, and automatic startup integration for personal operating systems.

---

## Key Milestone 2 Capabilities

### 1. Persistent Device Identity & Registration
- **Stable UUID Generation**: Hardware-bound unique identifier generated via uuid5(NAMESPACE_DNS, getnode() + hostname).
- **Identity Persistence**: Device identity cached securely in ~/.rio/device_id.json and synchronized with the FastAPI /api/v1/devices registry.

### 2. Bidirectional WebSocket Connection & Resilient Heartbeat
- **Persistent WS Gateway**: Connects via ws://<host>:<port>/api/v1/ws/device/{device_id} with auth tokens.
- **Heartbeat Loop**: Emits periodic health metrics (CPU, RAM, active tasks, latency) at 15s intervals.
- **Auto-Reconnection**: Exponential backoff reconnection policy (1s to 30s with jitter) on connection loss.

### 3. Granular Capability Permission Model
- **Explicit Access Controls**: Strict permission boundary covering:
  - system.execute (CLI / PowerShell commands)
  - screen.capture (Desktop screen analysis)
  - rowser.control (Headless/headful browser automation)
  - microphone.read (Audio & voice capture)
  - camera.read (Vision & camera capture)
  - ilesystem.read / ilesystem.write (Disk I/O)
- **Deny-by-Default Policy**: Commands requesting unpermitted capabilities are rejected before agent invocation.
- **CLI Permission Toggles**: io runtime permissions list/allow/deny <capability>.

### 4. Windows Startup & Process Lifecycle Supervisor
- **Registry Integration**: Auto-start configuration via HKCU\Software\Microsoft\Windows\CurrentVersion\Run.
- **Process Supervisor**: Manages child services, handles SIGINT/SIGTERM gracefully, cleans up active tasks, and flushes runtime health metrics to ~/.rio/health.json.
- **Tray Status Support**: Headless or pystray status indicators.
